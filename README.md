# Prestige CRM Enterprise Edition v2.0.0

## Description
Prestige CRM is a professional desktop customer relationship management application built with Electron, React, Express, and SQLite. Designed for enterprise-level business operations with a modern, intuitive interface.

## Features
- **Dashboard**: Real-time analytics with KPI cards and data visualization
- **Account Management**: Comprehensive customer account tracking
- **Contact Management**: Detailed contact information and relationships
- **Lead Management**: Track and qualify potential business leads
- **Opportunity Tracking**: Manage sales pipelines and forecasts
- **Order Management**: Process and track customer orders
- **Product Catalog**: Manage products and inventory
- **Quotation Builder**: Create professional quotes with PDF export
- **Contract Management**: Handle contracts and agreements
- **Invoice Processing**: Generate and track invoices
- **PR Requests**: Internal procurement request workflow
- **Equipment Loans**: Track equipment borrowing and returns
- **Document Management**: Centralized document storage
- **Import/Export**: Data migration and backup capabilities
- **Activity Tracking**: Log all customer interactions
- **Task Management**: Assign and track team tasks
- **Meeting Scheduling**: Organize and manage meetings
- **Communication Logs**: Record all communication channels
- **Template Manager**: Reusable document templates
- **Approval Workflows**: Configure multi-step approval processes
- **Notifications**: Real-time alerts and updates
- **Reports**: Business intelligence and analytics
- **Audit Logs**: Complete activity history and compliance
- **Settings**: Comprehensive system configuration
- **i18n Support**: English and Simplified Chinese

## System Requirements
- **Operating System**: Windows 10/11 (64-bit)
- **Processor**: 1 GHz or faster
- **RAM**: 2 GB minimum, 4 GB recommended
- **Storage**: 500 MB available space
- **Display**: 1280 x 720 minimum resolution

## Technology Stack
- **Frontend**: React 18, Ant Design 6, Chart.js
- **Backend**: Node.js, Express 4
- **Database**: SQLite (better-sqlite3)
- **Desktop**: Electron 33
- **Build**: Webpack 5, electron-builder
