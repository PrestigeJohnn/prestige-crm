# AI CRM - User Guide

## Getting Started

### System Requirements
- Windows 10 or later
- 4GB RAM minimum
- 200MB disk space

### Installation
1. Download `AI CRM Setup 1.0.0.exe`
2. Double-click to run the installer
3. Follow the installation wizard
4. Launch AI CRM from the desktop shortcut

## Features

### Dashboard
The dashboard provides an overview of your business with KPI cards, charts, and recent data.

### Accounts
Manage your customer accounts. Each account can have multiple contacts, opportunities, and activities.

### Leads
Track potential customers through your sales pipeline.

### Opportunities
Manage deals and track them through stages: Discovery → Qualification → Proposal → Negotiation → Closed Won/Lost.

### Orders
Track customer orders with status management.

### Activities
Log calls, emails, meetings, and other customer interactions.

### Tasks
Manage your to-do items with priority and due date tracking.

### Communications
Track all customer communications in one place.

### Meetings
Schedule and track meetings with calendar view.

### Contracts & Invoices
Manage contracts and generate invoices.

### Cases
Track customer support cases.

### Reports
View analytics and export data.

### Import/Export
Import data from CSV/Excel files or export your data.

### Settings
Configure application preferences, notifications, and security.

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| Ctrl+K | Global search |
| Ctrl+N | New item |
| Ctrl+S | Save |
| Escape | Close modal |

## Data Backup

AI CRM automatically backs up your data daily. You can also manually backup from Settings → Data & Backup.
