⚡ AI CRM — Installation

Follow these steps to install AI CRM as a desktop app:

Step 1: Install Electron (optional, for true desktop app)
Open Command Prompt as Administrator and run:
cd D:\AI-CRM && npm install electron --save-dev
Step 2: Double-click AI CRM.bat to launch
This starts the server and opens your browser automatically.
Step 3 (Optional): Create a desktop shortcut
Right-click AI CRM.bat → Send to → Desktop (create shortcut)
